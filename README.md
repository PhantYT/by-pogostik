# by pogostik

Пиксельный учебный хаб для первокурсников Высшей IT‑школы КГУ.

Публичный сайт: [phantyt.github.io/by-pogostik](https://phantyt.github.io/by-pogostik/)

## Возможности

- выбор всех семи групп набора 2026 года;
- официальное расписание ЭИОС с предметом, преподавателем и аудиторией;
- общие домашние задания и мероприятия по группам;
- регистрация через Sign in with ChatGPT;
- личный профиль с самостоятельным изменением имени и группы;
- роли `student`, `group_admin` и единственного `super_admin`;
- редактирование профилей и назначение администраторов групп владельцем сайта;
- полноразмерные современные треки Audius, поиск на русском и английском, автоматический следующий трек;
- открытый лицензированный каталог Internet Archive как резерв;
- бесконечный встроенный ambient без слов;
- адаптивный pixel‑UI и scroll‑parallax с фотографиями кампуса.

## Группы

`26-ИСбо-1` … `26-ИСбо-5`, `26-ИБбо-6`, `26-ПМбо-1`.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`. Кнопка входа использует опубликованный защищённый API и после авторизации возвращает пользователя на GitHub Pages.

## Проверка

```bash
npm run build
npm run build:pages
npm run lint
npx tsc --noEmit
```

## Данные и доступ

Интерфейс публикуется на GitHub Pages, а серверные данные хранятся в Cloudflare D1. Браузер не получает ключей базы. Схема находится в `db/schema.ts`, миграции — в каталоге `drizzle/`.

Вход подтверждает email через Sign in with ChatGPT. В GitHub Pages возвращается одноразовый двухминутный код, который обменивается на 12‑часовую сессию только для текущей вкладки. В D1 хранится только SHA‑256 хеш токена. Email из `OWNER_EMAIL` всегда получает роль владельца; по умолчанию это `vasmat2009@gmail.com`. Только владелец может изменять чужие профили и назначать администраторов групп.

API использует параметризованные SQL‑запросы, серверную проверку ролей и групп, строгую валидацию, ограниченный CORS для `phantyt.github.io`, короткий OAuth state cookie, срок действия и отзыв сессий. GitHub Pages дополнительно задаёт Content Security Policy и блокирует работу интерфейса во фрейме.
