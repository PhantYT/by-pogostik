# by pogostik

Пиксельный учебный хаб для первокурсников Высшей IT‑школы КГУ.

## Возможности

- выбор всех семи групп набора 2026 года;
- официальное расписание ЭИОС с предметом, преподавателем и аудиторией;
- общие домашние задания и мероприятия по группам;
- регистрация через Sign in with ChatGPT;
- роли `student`, `group_admin` и единственного `super_admin`;
- назначение администраторов групп владельцем сайта;
- полноразмерные современные треки Audius, поиск на русском и английском, автоматический следующий трек;
- открытый лицензированный каталог Internet Archive как резерв;
- бесконечный встроенный ambient без слов;
- адаптивный pixel‑UI и scroll‑parallax с фотографиями кампуса.

## Группы

`26-ИСбо-1` … `26-ИСбо-5`, `26-ИБбо-6`, `26-ПМбо-1`.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`. Служебные маршруты Sign in with ChatGPT работают только после публикации на Sites, поэтому локально сайт остаётся в режиме просмотра.

## Проверка

```bash
npm run build
npm run lint
npx tsc --noEmit
```

## Данные и доступ

Серверные данные хранятся в Cloudflare D1. Схема находится в `db/schema.ts`, миграция — в `drizzle/0000_initial.sql`.

Первый зарегистрированный пользователь, знающий секрет `SUPER_ADMIN_CODE`, активирует роль владельца в админке. После этого только владелец назначает и снимает администраторов групп. Все проверки доступа повторяются на сервере; клиентский интерфейс не является границей безопасности.

Секрет владельца задаётся как runtime environment variable и никогда не должен попадать в Git.
